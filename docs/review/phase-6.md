## 変更内容

### 1. デフォルトページャの変更（pager.rs）
- **変更内容**: Unix系のデフォルトページャを `less` から `less -R` に変更
- **目的**: ANSIカラーコードを解釈して色付き表示を行う
- **影響範囲**: 環境変数 `$PAGER` や `$GIT_PAGER` が未設定の場合のみ適用

### 2. Git差分コマンドへの色オプション追加（app.rs）
- **変更内容**: 以下の3メソッドで `git diff` / `git show` に `--color=always` を追加
  - `get_diff()`: Status View での差分表示
  - `get_commit_details()`: Log View でのコミット詳細表示
  - `get_commit_staged_diff()`: コミットモードでの staged diff 表示
- **目的**: ページャに色付き出力を渡す
- **影響範囲**: 差分表示時のみ（git コマンドの呼び出しタイミングは変更なし）
