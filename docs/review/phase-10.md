## 変更内容

### 1. Push 機能（P キー）
- Status View で P キーを押すと確認ダイアログが表示される
- y/n で確認/キャンセル
- `git push` を実行し、成功/失敗をステータスバーに表示

### 2. Pull 機能（U キー）
- Status View で U キーを押すと事前チェックを実行
- 未コミットの変更がある場合は Pull を拒否し、メッセージを表示
- 変更がない場合のみ確認ダイアログを表示
- `git pull` 実行後、ステータスを自動更新

### 3. UI 更新
- ヘルプ画面に P:Push, U:Pull を追加
- Status View のステータスバーヒントに push/pull を追加
- Push/Pull 用の確認ダイアログを追加
